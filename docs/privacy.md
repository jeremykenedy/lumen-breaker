# Privacy and notices

Lumen Breaker runs entirely offline. Its manifest requests no permissions. It bundles no ads, analytics, tracking, reporting SDK, remote configuration or update checks. Gameplay and settings make no network requests. Preferences remain on the TV, and Android backup is disabled.

The separately invoked computer installer contacts GitHub only to download the requested release and its checksum, then uses ADB. This is separate from app runtime. GitHub may observe ordinary download request metadata.

Source code and original vector/Canvas artwork are Apache-2.0. [LICENSE](../LICENSE) and [NOTICE](../NOTICE) are bundled in the APK assets. There are no bundled third-party media, fonts or audio. Android framework APIs are provided by the device rather than redistributed dependencies.
