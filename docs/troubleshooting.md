# Troubleshooting

If installation fails, check the explicit ADB serial is connected and authorized. The installer reports failed commands and checksum problems. Do not bypass an APK signer mismatch; use the original signed release or back up local preferences before explicitly removing an unrelated install.

If the saver is absent from stock Settings, use a compatible picker. Installing alone does not select it. Confirm the selected component and ordinary idle behavior rather than treating Preview as proof. Fire OS may independently sleep or revert supported settings; the app does not disable platform updates or promise protection from every vendor action.

If options appear unchanged, close Preview and open a new scene. Randomize all overrides saved individual choices only for that scene. A sparse board may be a late round; actual brick collisions remove tiles, and a clear starts the next formation.

If motion is slow on an untested TV, report model/API/resolution and settings. Do not assume 4K from display marketing. The renderer uses actual View dimensions. Try the supported ball/effect choices; do not change OS power/security settings as a troubleshooting shortcut.
