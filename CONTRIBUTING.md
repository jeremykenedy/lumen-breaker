# Contributing

Keep gameplay continuously animated and offline. Preserve the unique package identity and signing continuity. Make tests prove behavior and edge cases; keep physics/options independent of Android. Do not include device identifiers, credentials, personal logs or signing files.

Run the checks in [building](docs/building.md). Renderer changes need actual native moving inspection; emulator pacing does not establish physical performance. Preserve other apps and device configuration during tests. Do not reboot a user's TV or change timers to accelerate a normal idle test.
