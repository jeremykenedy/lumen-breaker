# Changelog

## Unreleased: 1.0.0

### Major changes

- Original continuously playing ceramic brick-breaker with real collisions, finite paddle movement, misses and fresh rounds.
- Four formation families, four palettes and eight remote-friendly visual choices with randomization.
- Offline Dream and Preview with app-owned settings schema.

### Minor changes and fixes

- Restore opaque ceramic body rendering after drawing shared-Paint shadows.
- Add capture-derived native preview and device-specific verification notes.

### Upgrade guide

Initial public release preparation; no previous public Lumen release exists. Private builds with the same signing certificate can update in place and retain all nine saved values. Select the Dream separately after install. Removal deletes its local options.

### Breaking changes

None from a previous public release. Minimum SDK23 and target SDK36 are declared; see the tested-device matrix rather than assuming every-device support.

Publication, final packaging gate and independent visual review are pending.
