# Security

Do not post credentials, signing files or private device logs in public issues. Use GitHub private vulnerability reporting for a security flaw. Only published versions and their exact tagged source can be considered supported; this private preparation branch has no published release.

Runtime has no requested permissions or network access. The computer installer verifies official release bytes against the published checksum. A local APK override is explicitly caller-selected. A compromised release account or signing key is outside checksum validation alone.
